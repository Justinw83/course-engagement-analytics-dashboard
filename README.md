# Student Success Analytics Dashboard

## Project Overview

This project demonstrates an end-to-end analytics workflow using Python and Power BI. The objective was to identify data quality issues, create a reporting-ready dataset, analyze student engagement and course completion data, and develop dashboards that support business decision-making.

The project was designed to simulate the type of reporting, data validation, and dashboard development responsibilities commonly found in analytics and operations teams.

---

## Data Source

Dataset: "Predict Online Course Engagement Dataset"  
Source: Kaggle  
Link: https://www.kaggle.com/datasets/rabieelkharoua/predict-online-course-engagement-dataset

This synthetic dataset includes user engagement metrics from an online course platform.

---

## Business Problem

Online education organizations rely on accurate reporting and student engagement metrics to understand student success and identify opportunities for improvement.

The goals of this project were to:

* Assess student engagement across course categories
* Evaluate factors associated with course completion
* Identify data quality issues
* Create reporting-ready datasets
* Develop dashboards that communicate insights clearly to stakeholders

---

## Tools Used

* Python
* Pandas
* NumPy
* Power BI

---

## Data Quality & Validation

To simulate real-world reporting environments, data quality issues were intentionally introduced, including:

* Duplicate records
* Missing values
* Invalid quiz scores
* Invalid completion percentages
* Inconsistent category values

Python scripts were used to:

* Profile the dataset
* Identify data quality issues
* Standardize values
* Remove duplicates
* Prepare a clean dataset for reporting

---

## Key Metrics

The dashboards track:

* Total Students
* Course Completion Rate
* Average Quiz Score
* Average Time Spent on Course
* Course Performance by Category
* Student Risk Segmentation

---

## Dashboard 1: Executive Summary

This dashboard provides a high-level overview of student performance and engagement.

Key questions addressed:

* What is the overall course completion rate?
* Which course categories perform best?
* How do students engage with course content?
* What percentage of students are considered high-risk?

---

## Dashboard 2: Student Success Analysis

This dashboard focuses on identifying behaviors associated with successful course completion.

Key questions addressed:

* Does time spent on a course impact completion?
* Do quiz scores correlate with completion?
* Which course categories have the highest engagement?
* Are there differences between desktop and mobile users?

---

## Key Takeaways

* Students meeting a certain quiz score and time spent threshold are strongly associated with course completion.
* Programming courses have the highest completion rate, while health courses have the lowest.
* Data quality validation is essential before reporting results.
